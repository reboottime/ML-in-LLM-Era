# The Quizzes to LLMs

## Introduction

> 1. 有一張長方形壁報紙，長 36 公分、寬 40 公分,老師想要把它切成很多個一樣大的正方形,不要剩下，請問無法切出下列哪一種邊長的正方形?
(1)1公分
(2)2公分
(3)4公分
(4)6公分

- Solution: 正方形的长等于宽， 所以要把長方形壁報紙切成一樣大的正方形而不剩下，邊長必須是長（36公分）和寬（40公分）的共同因數.
- Learnings: All LLMs can solve this problem easily on 2025/08/06. In the homework guidance, the keyword provided to gemini is `Common Factor`.
