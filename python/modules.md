# Frequently Used Modules

- `asyncio`
  - What problem does it solve: It is similar to JavaScript `async` and `await`.
  - `Asyncio` is a package you can import to [write concurrent code using the async/await syntax.](https://docs.python.org/3/library/asyncio.html)
  - [A `asyncio` tutorial with unusual humor](https://www.youtube.com/watch?v=K56nNuBEd0c)
- `dataclass`
  - what problem does it solve: avoid duplicated class initialization and order related code
  - frozen: make instance immutable after creation
